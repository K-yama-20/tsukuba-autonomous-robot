## 読み（模擬だけ、各 1〜2 本）

- 蛇行：旋回の PI を止めた（onv）ので、直線では蛇行しなかった。free の直線区間の旋回の速さは、2 回目の全部の本で 0。表の sd は、角と回避の旋回の分。B は A より旋回がおだやか（free・cone_late で 0.27〜0.29、A は 0.38〜0.42）。
- 遅れて出るコーン：間隔は旋回の模型で決まった。
  - A：vx 0.4〜0.6 で 0.05〜0.16 m しか空かず、0.8 で接触した。
  - B：0.4・0.5 で 0.51〜0.53 m 空いた。0.6 では 2 本のうち 1 本で接触した。
  - 推測：B では MPPI の模型の旋回が遅いので、早めに大回りして避ける（最大の横ずれ 1.14 m、A は 0.74 m）。データから仕組みを直接は確かめていない。
- P22（人）：接触なし、間隔 0.45〜0.77 m。B の 0.4 と C は大回りした（横ずれ 1.9〜2.4 m）。
- C は B（vx 0.5）より、コーンの間隔が少し広い（0.56 m と 0.51 m）だけ。遅くなり（90 s と 84 s）、大回りが大きい（横ずれ 2.2〜2.4 m）。推測：1.8 m の通路では通路を外れる。

## 速度マスクの影響（実車にも関わる）

- 上流の nav2_mppi_controller 1.3.13 の optimizer.cpp の setSpeedLimit（504〜510 行）：絶対値の速度制限では、ratio = 制限 / vx_max（設定の値）をかけて、vx_max・vx_min・vy・wz を全部変える。ratio が 1 を超えると引き上げる。
- Gouda の速度マスクは type 2（絶対値、speed_mask.py・nav2_config.py）。waypoint の各区間には正の制限がある（waypoints.py）。
- 模擬の例（`results_r2_speedmask1.25.md`）
  - 試験の区間の制限 1.25 m/s・vx_max 0.4 で、指令が約 0.845 m/s（＝0.27×1.25/0.4）に張り付いた。
  - 車体は 0.63〜0.72 m/s で走り、横ずれ 1.08〜1.46 m、P22 の人に接触した（間隔 −0.05）。
  - この 2 本は表から外し、区間の制限を vx_max と同じにして組を全部走らせ直した。
- 推測（実車）：区間の制限が vx_max より大きいと、vx_max を下げても遅くならない。逆に vx_min（PRM-162）と wz が上がる。
