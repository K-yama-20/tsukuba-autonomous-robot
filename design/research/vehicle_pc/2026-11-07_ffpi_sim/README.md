## ゲインの探索（Python だけ、`sweep.py`・`sweep2.py`・`weave.py`）

- 層あり：0.62〜0.78 s で動き出す（車体モデルの 0.6 s の遅れで決まる）。0.12 m/s 以上の目標では、定常の差はほぼ 0。

- 積分の上限 0.3：遅れ 0.3 s で最大 +0.34 m/s 行き過ぎた。原因は始動の遅れの間に積分がたまること。上限 0.15 は +0.05〜0.16。

## 読み（模擬だけ、多くは各 1 本）

- 層があると、MPPI の open_loop false でも動き出す（層なしは 0/2、層あり・遅れ 0.1 の free は 4/4）。
- MPPI の open_loop true では、層で次のように変わった。横ずれは悪くなっていない。
  - 平均の速度：0.40 → 0.60 m/s
  - 動き出し：約 1.3 → 約 0.7 s
  - 速度の差：0.20 → 0.01 m/s
- 旋回の PI は蛇行する。走行中の旋回の sd は 0.02 → 0.15（遅れ 0.1）・0.23（遅れ 0.3）。旋回をフィードフォワードだけにすると約 0.055 で、速度とゴールは同じ。
- 遅れ 0.3 s と open_loop false の組では、動く・止まるの繰り返し（31〜32 回）でゴールできなかった。open_loop true と RPP では、遅れ 0.3 も 0.1 とほぼ同じ。
- 遅れて出るコーンには、層ありの 9 本すべてで接触した。層なし・open_loop true では接触しなかったが、0.19〜0.38 m/s と遅かった。層で速くなった分、回避の余裕が減った（#61 の open_loop の結果と同じ傾向）。
- RPP は層の有無でほぼ同じ。RPP は 1.25 m/s を求め、車体モデルは約 0.98 m/s で頭打ちになり、倒し量は上限に張り付く。
