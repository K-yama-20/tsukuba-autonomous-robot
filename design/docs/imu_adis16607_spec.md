# IMU の仕様（ADIS16607-2）

IMU について考えるときは、この表の値を使う。一般的な値で考えない（DEC-418、CLAUDE.md 1.13）。

- 製品：TR-IMU16607 基板の ADIS16607-2（第178便より前の記録と DEC の人の記載）
- 原本：Analog Devices ADIS16607 Data Sheet Rev. 0（9/2026）、Table 1、p.5〜7。人の手元の写しを AI が直接読んだ（SHA-256 先頭 1e8d67c4312e4b96）。著作物なのでリポジトリには入れない
- 値は標準（Typ）、記載のあるものは 1σ。実機の個体の測定ではない
- 原本の 1g は 9.797464 m/s²

## TR-IMU16607 基板の設定と出力（ファームとドライバのソース、第213便）

読んだソース：
- ファームは technoroad/TR-IMU2-STM32 の 1ffaad4（v1.1、2026-08-31 の公開ソース）。
- ドライバは technoroad/ADI_IMU_TR_Driver_ROS2 の 742b7ba（`third_party/drivers.repos` で固定、車載 PC の写し）。
- 基板に書き込まれたファームのビルド日は 20260630（TR-IMU Monitor v1.1 の表示）。公開ソースと同じ版かは未確認。

| 設定（TR-IMU Monitor の名前、コマンド） | 出力への効き方（ソースで確かめたこと） | 場所 |
|---|---|---|
| 重力補正（0x76） | フラグは保存・設定コマンド・設定の読み出しの 3 か所にしか出てこない。加速度・角速度の計算にもテレメトリにも使われていない。初期値は true | ファーム `flash_ctrl.c:89`、`configure_cmd.c:87`、`send_ack.c:196`、`main_app.h:33` |
| 加速度の出力 | テレメトリは ADIS の生のカウント値。ドライバは「カウント ÷ 感度 × 9.80665」で m/s² にする。`/imu/data_raw` の加速度は重力を含む | ファーム `send_ack.c:127`、ドライバ `adis_rcv_bin.cpp:491` |
| 16bit／32bit 読み込み（0x74） | 16bit は上位 16 bit。32bit は実質 24 bit（`>> 8`）で、細かさは 16bit の 256 倍。感度はモードに合わせて設定の読み出しで返り、ドライバは起動のたびにそれで換算する。モードを変えてもドライバの変更は要らない | ファーム `adis_type3_ctrl.c:355・379`、`imu_select.c:235-258`、ドライバ `adis_rcv_bin.cpp:485・497` |
| 感度（ADIS16607-2） | 32bit：ジャイロ 16000 LSB/(°/s)、加速度 200000 LSB/g。16bit：それぞれ 62.5、781.25（Monitor の表示と一致） | ファーム `imu_select.c:241-258` |
| 姿勢推定フィルタ（0x75） | 姿勢はクォータニオンとして別の欄で出る。加速度・角速度の生の値は変えない | ファーム `send_ack.c:121-131` |
| 入力ピン（0x77） | IN0（PPS 用）の設定。Gouda は使っていない | — |

計算：16bit の 1 目盛りは、ジャイロ 0.016 °/s、加速度 1.28 mg。出力ノイズ（ジャイロ 0.17 °/s RMS、加速度 3.9 mg RMS、上の表）と比べると、ジャイロは十分小さく、加速度は同じ程度。
