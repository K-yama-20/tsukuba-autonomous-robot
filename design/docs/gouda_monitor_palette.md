# gouda_monitor の配色（DEC-399、案 A）

対象は gouda_monitor の画面（`gouda_core/web/`）。この文書の色は、`gouda_gui_design_rules.md` §2 の背景・通常情報・注意の色に代わる。同文書のほかの節（形状、配置、色だけで伝えない、警告ではない情報を赤にしないなど）はそのまま。gouda_gui の画面は変えていない。

| 用途 | 色 | 背景に対する比（WCAG、計算） |
|---|---|---|
| 背景 | `#F0F0F0`、ヘッダ `#E8E8E8` | |
| 入力欄・表示欄 | `#FFFFFF` | |

| 補助文字 | `#5D5D5D` | 5.78（ヘッダ上 5.37、選択行上 4.89） |

| 選択中のタブ | `#333333` に白文字 | 12.63 |

## 地図の上の印

地図の画像の上に描くので、画面の背景に合わせない。

| 印 | 色 |
|---|---|
| 地図の外 | `#808080` |
| 走行禁止 | 線 `#ce0000`、面は同じ色の 30 % |
| 走行可 | 線 `#197a4b`、面は同じ色の 25 % |
| 経路 | 黒の線に白の縁 |
| waypoint | 黒の点に白の縁（最初の点は黄 `#f2e700` に黒の縁）、番号は白地に黒 |
| 禁止域の間の狭い箇所 | 黒の破線と黒の文字 |
| 地図作成の終わり | 濃い黄 `#6B5900` |
| 初期位置 | `#A0006E` |

## 根拠と限り

- 色の意味（赤＝異常、黄＝注意、緑＝正常）は JIS B 9960-1:2019 表4 と JIS B 9706-1:2009 表2 を画面に準用した。hex 値は JIS にはなく、公開デザインシステムの値と計算で決めた提案である。JIS は転載で読んだもので、原本未照合。
- 実機の表示装置と周囲の明るさでの見え方は未確認。明背景を選んだのは人の判断で、実測の根拠はない。
- 色は停止の保証ではない。緑の表示や赤の非表示を、安全の根拠にしない。
- 調査の報告はリポジトリの外の `reports/HMI配色のJIS規格と推奨色.md`。
