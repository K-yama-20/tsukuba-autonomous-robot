# gouda_gui デザインルール

宇宙戦艦ヤマト2199以降の地球側CICを参照した、Goudaの運行管制GUIのデザインルール。

## 1. 基本方針

- 地球側CICの情報設計の文法を参照する。作品の画面を直接複製しない。
- 主表示、状態欄、数値欄、ログ欄を同居させ、運行状態を一覧できる構成とする。
- UIと表示内容を先に完成させ、アニメ的な演出は後段とする。
- 情報の意味、可読性、実データの正確な表示を優先する。

## 2. 配色

| 用途 | 色 |
|---|---|
| 背景 | 深緑または濃紺 |
| 通常情報 | シアン〜青緑 |
| 注意・未確認・選択 | アンバー |
| 停止・重大異常 | 赤 |

- 警告ではない情報を赤にしない。
- 色だけで正常・異常を伝えず、状態語と説明を併記する。
- ガミラス側の蛍光緑を中心とした表現ではなく、地球側の配色を基準とする。
- 厳密なHEX値は確認できた仕様では未指定。

## 3. 形状・文字・動き

- 細い矩形フレームと、角を強調したブラケットを使う。
- 小さい英数字コードと日本語の状態語を組み合わせる。
- 読めないほど小さい文字を使わない。
- 同心円、距離環、座標グリッドは、情報上の意味がある場合に限って使う。中央の外部表示領域には追加しない。
- 発進準備は工程を順番に成立させるシーケンスとして表現する。
- 装飾目的の点滅やループアニメーションを使わない。
- 作品画像、ロゴ、固有艦影、専用フォントを無断で組み込まない。
- 書体名、文字サイズ、線幅、余白の厳密な数値は確認できた仕様では未指定。

## 4. 全体レイアウト

- 横長16:9、基準1920×1080相当。
- 本番の主要運行画面には縦スクロールを設けない。
- 中央を大きく使い、周囲を状態情報が取り囲む構成とする。
- 中央左：Navigation。Nav2の状態・経路などを外部ソフトウェアで描画する領域。
- 中央右：LiDAR / localization。XT-32点群と自己位置推定結果を外部ソフトウェアで描画する領域。
- 下段：ESP32 CONTROLLERとCONTROL PC / ROS 2を別ブロックにする。
- 右上：自律走行、手動操縦、停止を常設し、全タブから利用可能にする。モーダルやタブの背後へ隠さない。
- 旧下部の一時停止、安全停止／DISARMボタンは置かない。
- 旧下部の物理非常停止説明文は運行画面へ置かない。
- 発進準備タブにDESIGN RULEセクションを置かない。
- 異なる解像度では情報の優先順位を保って再設計する。文字を読めない大きさに縮小して16:9を維持しない。

## 5. CIC風デザインの適用範囲

適用する領域：

- 共通ヘッダとタブ
- モード操作とステータスストリップ
- ESP32／制御PCのhealth表示
- イベントとログ
- 発進準備
- ポータブル電源と通信
- 較正・解析

NavigationとLiDAR / localizationの外部表示領域内部には適用しない。

## 6. 中央2面の所有境界

- 中央2面の画素生成はRViz2等の外部可視化ソフトウェアが担当する。
- gouda_guiは表示領域を確保し、その外側にタイトル、接続状態、鮮度、主要数値を配置する。
- 描画内容を再実装、再装飾、再着色しない。
- 同心円、識別スタンプ、コード列、カウンター、照準枠、走査線、色フィルタを内部に重ねない。
- 外部描画をCIC風に見せるための色変換、走査線、発光フィルタを適用しない。
- costmap、path、pose、point cloudを独自canvas、SVG、WebGL、QML Scene Graph等で重複描画しない。
- 配色、グリッド、カメラ、ツール、凡例、操作方法は外部ソフトウェア側の設定に従う。
- 外部プロセスの停止や応答停止、topic stale、ウィンドウ取得失敗を、静止画や架空描画で隠さない。外側にUNAVAILABLE、STALE、DISCONNECTED等を表示する。
- 外部表示への操作入力が、モード操作やSTOP操作を奪わないフォーカス規則を設ける。

## 7. 状態・数値の表示

- 未受信をOKとして表示しない。
- STALEとERRORを区別する。
- コードだけでなく、人が読める説明と発生時の値を表示する。
- 同じイベントが連続しても、件数と最終時刻を失わない。
- 正常メッセージの受信だけでlatched faultを自動的に消さない。
- ユーザーの確認と原因の解消を区別する。
- 数値を埋めるための架空データを使わない。
- ポータブル電源の更新が止まった場合、最後のSOCとageを保持してSTALEを表示する。切断時はDISCONNECTEDとし、SOC 0%とデータ不明を区別する。

## 8. 復元元と未確定事項

復元元：

- `emc270-control-pc/AGENTS.md` 第10章「16:9 UI要求」、特に10.1・10.3・10.7、および第11・12章の状態表示規則。
- `yamato_earth_ui_reference_catalog.md`「地球側UIのデザイン文法」。

この文書は保存済みの要求を整理したものであり、過去の会話全文を復元したものではない。新たな色コード、フォント、寸法は追加していない。

元仕様にはKISS-ICPの表記が残っている。現在のGLIM採用方針に合わせ、本書では自己位置推定をlocalizationと表記した。表示の所有境界は元仕様どおり保持している。

外部表示の埋込み方式、同一／別RViz2プロセス、起動・再起動・監視方式は元仕様で未確定。
