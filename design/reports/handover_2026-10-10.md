## 5. Ubuntu（VM）の使い方

```
ssh -o BatchMode=yes aya@10.211.55.4 'source /opt/ros/jazzy/setup.bash; cd ~/gouda_ws/src/tsukuba-autonomous-robot && git fetch -q origin design/gate3-baseline-2026-10-09 && git checkout -q -B design/gate3-baseline-2026-10-09 FETCH_HEAD; cd ~/gouda_ws && colcon build --packages-select gouda_interfaces gouda_core; source install/setup.bash; cd src/tsukuba-autonomous-robot && python3 -m unittest discover -s gouda_core/test'
ssh ... 'source /opt/ros/jazzy/setup.bash; source ~/gouda_ws/install/setup.bash; export GOUDA_WORKSPACE=$HOME/gouda_ws GOUDA_TRIAL_PARAMS=1; cd ~/gouda_ws/src/tsukuba-autonomous-robot; bash gouda.sh start; cat ~/gouda_ws/gouda_data/run/monitor.url; bash gouda.sh stop'
```
