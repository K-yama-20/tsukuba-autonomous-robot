## 2. 自律判断した変更と理由

- プロトコル v4 の各選択（`docs/esp32_protocol_v4.md` §1 の表に理由。旧 v3・参照 firmware との振る舞いの差は §7）。
- IFD-38 は `diagnostic_msgs/DiagnosticArray`（標準型。項目を key/value で載せ、取得できない項目は載せず monitor が「不明」と表示）。
- ND-11・ND-12 は lifecycle node。非活性では何も送らない（手動走行・地図作成で非中立を送らない）。launch は UNCONFIGURED で起動し、活性化は IFD-36（5-6／5-7 の mode_manager）か試験の `ros2 lifecycle set`。
- bridge の軸対応: axes[0]=前後→y、axes[1]=旋回（左 +）→x=−turn（firmware の x は右 +）。符号の実車確認は Q-03。
- firmware のビルド時設定は generated/params/firmware_config.yaml から `tools/gen_build_config.py` が生成（`esp32dev`＝承認値のみ。DAC 値なしのため has_config=false で DAC 非書込。`esp32dev_trial`＝仮値入り、卓上専用）。生成器 `generate_params.py` に `firmware_config.trial.yaml` の出力を追加（実装層の変更。生成物は再生成し DR-15 一致）。
- 仮値の追加（PRM-09=0.35、PRM-14=0.1、PRM-16=0.2 s）: モデルに書かれた関係条件（PRM-08 より短く PRM-14 より長い、PRM-13 の 1/5 以下、PRM-08 より短い）を満たす stub 専用値。実車採用値ではない。
- 変更セット REV-027 の `append` をネストキーに使えないことが判明（スキーマ違反→検査全体が連鎖失敗）。原因分類: 実装（変更セットの書き方）。`set_nested` で全リストを与える形に書き直し、正本は `git checkout` で戻してから再適用。
- DR-15 の未判定: docstring「stage 5-5.」が承認値 5.0 の走査形「5.」に一致。原因分類: 実装（表記）。表記を変更。検査器は変えていない。
- 試験の失敗 3 件（Python 模擬 firmware）: 原因分類: 試験（期待の起点の誤り。手動解放の待ちは「手動が最後に有効だった時刻」から数える設計。不正 token フレームで試験側が seq を進めていた）。設計・実装は変えず試験を修正。
- C++ ホスト試験の失敗 1 件: 原因分類: 試験（試験が送信バッファを drain せず 1 KB を超えた。実機 main.cpp は毎 loop で drain する）。試験を修正。
- VM 試験 script: `set -u` が ROS の setup.bash で失敗（試験基盤。-u を外した）。前チャットから残っていた gouda_core 起動（pid 173536）が Part B を阻害（試験基盤。開始前に stop を追加し、Part B を再実行）。

## 6. 残るリスク

- firmware は実機で未実行。Bluepad32 の接続コールバックでの機種判定（`isGamepad()` が最初の報告前に false になりうる旧 firmware の注記）を踏襲したが、実機で再確認が必要。
- DAC の電圧は要求値であり測定値ではない（PRM-43〜46 未確定）。EMC-270 側の中立の実電圧と端点は Q-03 の実測が必要。
- 旧 v3 と異なり BT 途絶で PC 指令源を無効化しない（PC 指令源の期限は PC 指令だけで判定。手動解放の待ち PRM-48 は適用）。振る舞いの差は `docs/esp32_protocol_v4.md` §7 に列挙。人の確認対象。
- PC 側 motion_hold の期限（PRM-42）は PRM-16 の周期発行が前提。PRM-16 未確定（実車では publish-on-change のみ）だと、実車で hold=false のまま mode_manager が停止した場合は hold 期限切れ（0.5 s 仮値）で中立になるが、周期発行がないと「期限切れ」が常に起きて自律走行できない。5-6 の前に PRM-16 の値（または周期発行の採用）を決める必要がある。
- Nav2 の cmd_vel が TwistStamped（PRM-12）に決まった場合、ND-11 の購読型の変更が必要。
