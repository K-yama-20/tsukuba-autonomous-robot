## 3. 結果（地図 20261019_123731_dc7b4c8a/converted/002、軌跡の 200 行目、模擬の点群）

| ずれ | 結果 |
|---|---|
| 0 m・90° | 正しい（誤差 0.07 m・0°、15 s までに正常） |
| 0 m・180° | 正しい（0.07 m・0°、30 s までに正常） |
| 1 m・90° | 正しい（0.07 m・0°、30 s までに正常） |
| 3 m・0° | 正しい（0.07 m・0°、30 s までに正常）。その後、5 s の間の決定の記録で、推定不能（ndt_diagnostics が古い・EKF の姿勢の更新なし 80 回）と正常を数回行き来した |
| **5 m・0°** | **誤り**：入力の近く（5.86 m 離れた位置）に合い、NVTL 2.67（しきい値 2.3 以上）で「正常」と判定した |

- 向きのずれは原因ではない（90°・180° でも正しい）。位置のずれ 5 m で失敗した。
- 以前の REV-128 の 5 m・90° は NVTL 2.03 で推定不能（誤りを正常にしなかった）。今回の 5 m・0° は誤りを正常にした。NVTL のしきい値だけでは誤った位置を見分けられない場合がある。
- 各回の最後に「gouda_a3_points ... process has died, exit code -2」が出るのは、片付けの SIGINT のときの表示（5 s ごとの値では、窓の間ずっと点群が NDT に届いている）。
